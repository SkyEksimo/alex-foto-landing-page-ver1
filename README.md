# 📸 Photography Portfolio & Landing Page

A responsive, modern landing page designed for a professional photographer portfolio. 

---

## 🛠️ Tech Stack
- **HTML5:** Semantic structure, modals, integrated Google Maps iframe
- **CSS3:** Flexbox, CSS Grid, custom animations (`@keyframes pulse`), responsive layout
- **JavaScript (Vanilla):** Interactive modal windows for specialization details

---

## 📱 Features
- Interactive modals for service showcases
- Responsive image grid gallery with Instagram CTA
- Embedded Google Maps location
- Smooth scroll & hover effects
